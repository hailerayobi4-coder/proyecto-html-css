# 💻 Proyecto Web - Ingeniería de Sistemas

Este proyecto es una página web desarrollada en HTML y CSS que presenta información general sobre la Ingeniería de Sistemas, su importancia, áreas de desempeño y competencias profesionales.

El objetivo principal del proyecto es aplicar buenas prácticas de desarrollo frontend junto con el uso de Git como sistema de control de versiones, implementando un flujo de trabajo basado en ramas (Git Flow simplificado), convenciones de commits y trabajo colaborativo simulado.

## 🚀 Tecnologías Utilizadas

- HTML5
- CSS3
- Git
- GitHub

## 🌱 Metodología de Trabajo

Se implementó:
- Rama `main` como versión estable.
- Rama `develop` para integración.
- Ramas `feature/*` para desarrollo de funcionalidades.
- Convenciones de commits (Conventional Commits).

## 🎯 Objetivo Académico

Aplicar Git como herramienta de control de versiones en un entorno de trabajo colaborativo simulado, fortaleciendo habilidades en gestión de código y organización de proyectos.
